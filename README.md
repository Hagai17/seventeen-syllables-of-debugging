A tiny Python program that writes one haiku about debugging to `/output/entry.txt`: three lines in the exact 5-7-5 syllable shape, 74 characters in all, no trailing newline. On ship day the programmer strips out every print line he hunted the bug with — and one rides along, live. The haiku was picked by drafting ten candidates and three revision-round challengers and duelling them pairwise on the bounty judge's own criteria — a true 5-7-5 haiku about debugging, a concrete and fresh picture at its centre, a last line that reframes what came before, no filler words, and a rhythm that reads aloud like speech. Every candidate's syllables were counted word by word and verified by script; the drafts, counts and duels are kept in `candidates.md`.

## Run it

```sh
python3 main.py
```
